<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| static file → browser | public/ files served directly by Express static middleware — no server-side processing |
| client/index.html → build artefact | client/index.html is the Vite source; public/index.html is the deployed artefact. They must be kept in sync manually (build.sh skips rebuild when public/index.html exists) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-01 | Tampering | public/index.html out of sync | mitigate | Task 3 edits both files explicitly; Task 4 grep-checks both |
| T-16-02 | Denial of Service | WebP >150KB increases LCP | mitigate | Task 1 retries at -q 70 then -q 60; Task 4 checks byte count |
| T-16-03 | Spoofing | /privacy URL intercepted by SPA catch-all | mitigate | File named privacy.html (not /privacy); Express static serves it before catch-all fires |
| T-16-04 | Information Disclosure | nanobanana PNG path not found | accept | Task 1 has explicit skip-and-document fallback; existing hero PNG remains functional |
| T-16-05 | Tampering | Invalid JSON-LD breaks structured data | mitigate | Task 4 grep confirms FAQPage present in both files; executor must validate JSON syntax before commit |
</threat_model>
