### Task 2: Build and dev-server smoke checks
**Type:** execute
**Files:**
- `.planning/phases/11-security-check-review-dependabot-alerts-and-address-each-ale/11-VERIFICATION.md` (append section)

**Steps:**
1. Run `cd web-version/client && npm run build` and confirm exit 0; record build duration and output size summary
2. Verify `public/index.html` is fresh (mtime within last hour)
3. Determine server port: `grep -E 'PORT|listen' web-version/server.js | head -5` — use port found (default likely 3000 or 5000)
4. Start `cd web-version && npm start` (background) and wait 5s
5. Smoke test endpoints (substitute port from step 3):
   - `curl -s -o /dev/null -w "%{http_code}\n" http://localhost:<PORT>/` → expect 200
   - `curl -s -o /dev/null -w "%{http_code}\n" http://localhost:<PORT>/api/settings` → expect 200/401 (existing behavior, NOT 500)
   - `curl -s -o /dev/null -w "%{http_code}\n" http://localhost:<PORT>/api/playlist/test-id/all` → expect non-5xx (404 acceptable for fake id; 500 not acceptable)
6. Kill the server
6. Write results to `11-VERIFICATION.md` under header `## Build + Smoke Results`

**Verification:**
- [ ] Client build passes (SEC-07)
- [ ] `public/` is fresh
- [ ] Dev server boots without errors (SEC-08)
- [ ] All three endpoint smoke tests return non-5xx (SEC-08)
