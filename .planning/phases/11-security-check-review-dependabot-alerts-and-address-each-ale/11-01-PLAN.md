# Phase 11 Plan 01: Baseline + Root basic-ftp Patch

## Meta
- **Phase:** 11
- **Plan:** 01
- **Requirements:** SEC-01, SEC-02, SEC-07
- **Depends on:** none
- **Estimated complexity:** low

## Objective
Capture the GitHub Dependabot alert baseline (SEC-01) and patch the root `basic-ftp` transitive dependency to `>=5.3.0` via `npm overrides` (SEC-02), preserving root build behavior (SEC-07).

## Context
The root `package-lock.json` carries `basic-ftp 5.2.2` as a transitive of `puppeteer → @puppeteer/browsers → proxy-agent → pac-proxy-agent → get-uri → basic-ftp` (verified pre-research). Per D-01, we use the `overrides` field — NOT a parent bump, which would touch puppeteer's full subtree. Per D-13, we capture the alert baseline first so we can prove SEC-09 closure later.

## Tasks

### Task 1: Capture Dependabot alert baseline
**Type:** execute
**Files:**
- `.planning/phases/11-security-check-review-dependabot-alerts-and-address-each-ale/11-01-baseline.json` — alert state snapshot

**Steps:**
1. Run `gh api repos/MrAshRhodes/suno-playlist-downloader-web/dependabot/alerts?state=open --paginate > .planning/phases/11-security-check-review-dependabot-alerts-and-address-each-ale/11-01-baseline.json`
2. Confirm the file contains all 11 alerts listed in `DEPENDABOT-ALERTS.md` (jq length check: `jq 'length' .planning/phases/11-security-check-review-dependabot-alerts-and-address-each-ale/11-01-baseline.json` should return 11 or more)
3. Confirm alert #75 (`basic-ftp`) is present in the snapshot

**Verification:**
- [ ] `11-01-baseline.json` exists and is valid JSON (`jq . <file>` exits 0)
- [ ] Snapshot includes alert number 75 with package `basic-ftp` (`jq '.[] | select(.number==75) | .security_vulnerability.package.name' .planning/phases/11-security-check-review-dependabot-alerts-and-address-each-ale/11-01-baseline.json` returns `"basic-ftp"`)

### Task 2: Confirm basic-ftp dep tree
**Type:** execute
**Files:**
- (read-only) `package.json`, `package-lock.json` at repo root

**Steps:**
1. Run `npm ls basic-ftp` from repo root and capture output
2. Verify the chain resolves through `puppeteer → @puppeteer/browsers → proxy-agent → pac-proxy-agent → get-uri → basic-ftp` as expected from pre-research
3. If a different parent appears (e.g., direct dep elsewhere), STOP and surface to user before proceeding

**Verification:**
- [ ] `npm ls basic-ftp` exits 0 and shows current version `5.2.2`
- [ ] Parent chain matches pre-research finding (via puppeteer)

### Task 3: Add overrides.basic-ftp and regenerate lockfile
**Type:** execute
**Files:**
- `package.json` — add `overrides` field
- `package-lock.json` — regenerated by npm install

**Steps:**
1. Run `npm audit fix` from repo root — per D-11, try automated fix first. Run `npm ls basic-ftp` to check if version is now `>=5.3.0`. If yes, skip steps 2-3 and go to step 4.
2. (Only if step 1 did not resolve) Read current `package.json` at repo root.
3. (Only if step 1 did not resolve) Add top-level field: `"overrides": { "basic-ftp": ">=5.3.0" }` (per D-01); if `overrides` already exists, merge in the `basic-ftp` key. Then run `npm install` from repo root to regenerate `package-lock.json`.
4. Run `npm ls basic-ftp` and confirm resolved version is `>=5.3.0`
5. Run `npm audit --json` and confirm there are zero advisories matching `"module_name": "basic-ftp"` (jq filter: `jq '.vulnerabilities | to_entries[] | select(.key=="basic-ftp")' audit.json` returns empty)

**Verification:**
- [ ] `package.json` contains `"overrides": { "basic-ftp": ">=5.3.0" }` (or merged equivalent)
- [ ] `npm ls basic-ftp` shows version `>=5.3.0`
- [ ] `npm audit` reports no findings for `basic-ftp`
- [ ] `package-lock.json` is regenerated and committable (no merge conflicts)
